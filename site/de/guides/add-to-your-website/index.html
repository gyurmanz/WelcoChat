Widget auf Ihrer Website einbinden

Funktioniert mit WordPress, Wix, GoDaddy, Squarespace, Shopify und jeder Seite, in die sich benutzerdefinierter Code einfügen lässt

Das WelcoChat-Widget besteht aus einer einzigen Codezeile — einem <script>-Tag mit der eigenen ID Ihres Agenten. Sobald Ihr Agent aktiv ist, kopieren Sie den Code auf der Einrichtungsseite Ihres Dienstes im Portal und fügen ihn dann anhand der folgenden Anleitung für Ihre Plattform in Ihre Website ein. Das Widget erscheint danach automatisch auf jeder Seite — ohne Gestaltungsaufwand und ohne Installation pro Seite.

WordPress

  1. Gehen Sie in Ihrem WordPress-Dashboard zu Plugins → Installieren, suchen Sie nach "WPCode" (oder "Insert Headers and Footers") und installieren und aktivieren Sie es.
  2. Öffnen Sie das Plugin — meist unter Code Snippets → Header & Footer in der Seitenleiste.
  3. Fügen Sie Ihren WelcoChat-Code in das Feld Footer ein, damit er nach dem Seiteninhalt geladen wird.
  4. Klicken Sie auf Speichern. Das Widget erscheint nun auf jeder Seite Ihrer Website.
  5. Tipp: Falls Ihr Theme bereits eine Einstellung "Custom Code" oder "Header/Footer Scripts" bietet — bei vielen Elementor- und Astra-Themes ist das der Fall — können Sie den Code auch dort direkt einfügen, ohne ein Plugin zu installieren.

Wix

  1. Öffnen Sie Ihre Website im Wix-Editor und gehen Sie zu Einstellungen → Benutzerdefinierter Code (oder suchen Sie oben nach "Benutzerdefinierter Code").
  2. Klicken Sie auf + Code hinzufügen.
  3. Fügen Sie Ihren WelcoChat-Code in das Codefeld ein.
  4. Wählen Sie unter Code zu Seiten hinzufügen die Option Alle Seiten. Wählen Sie unter Code platzieren in die Option Body – Ende.
  5. Klicken Sie auf Übernehmen und veröffentlichen Sie Ihre Website.

GoDaddy Website Builder

  1. Gehen Sie in Ihrem GoDaddy-Website-Builder-Dashboard (Websites + Marketing) zu Einstellungen → Website-weiter Code (bei manchen Tarifen unter Einstellungen → Erweiterte Tools → Benutzerdefinierter Code; verfügbar ab dem Commerce-Tarif).
  2. Fügen Sie Ihren WelcoChat-Code in das Feld Footer oder Body ein.
  3. Klicken Sie auf Speichern und veröffentlichen Sie Ihre Website erneut.
  4. Falls Ihr GoDaddy-Tarif keine Code-Einbindung bietet oder Ihre Website tatsächlich WordPress bei GoDaddy ist, verwenden Sie stattdessen die WordPress-Anleitung oben.

Squarespace

  1. Gehen Sie im Squarespace-Dashboard zu Einstellungen → Erweitert → Code-Einbindung (erfordert mindestens den Business-Tarif).
  2. Fügen Sie Ihren WelcoChat-Code in das Feld Footer ein, damit er auf jeder Seite geladen wird.
  3. Klicken Sie auf Speichern.

Shopify

  1. Gehen Sie in Ihrem Shopify-Adminbereich zu Online-Shop → Themes.
  2. Klicken Sie bei Ihrem aktuellen Theme auf Code bearbeiten.
  3. Öffnen Sie theme.liquid im Ordner Layout.
  4. Fügen Sie Ihren WelcoChat-Code direkt vor dem schließenden </body>-Tag ein.
  5. Klicken Sie auf Speichern.

Jeder andere Website-Baukasten

Jede andere Plattform, die uns begegnet ist — Webflow, Weebly, Jimdo, Carrd, Framer, eine handcodierte Website oder Ihr eigenes CMS — funktioniert nach demselben Prinzip: Suchen Sie nach einer Einstellung namens "Benutzerdefinierter Code", "Header- & Footer-Skripte", "Code-Einbindung" oder "Tracking-Codes" — dort werden meist auch Live-Chat-Tools und Analyse-Skripte eingefügt — und fügen Sie den Code dort ein, damit er auf jeder Seite geladen wird. Ist Ihre Website reines, handgeschriebenes HTML, fügen Sie den Code direkt vor dem schließenden </body>-Tag jeder Seitenvorlage ein.

Prüfen, ob es funktioniert

Öffnen Sie nach dem Veröffentlichen Ihre Live-Website in einem neuen Browser-Tab — nicht die Editor-Vorschau — und die WelcoChat-Blase sollte in der unteren Ecke erscheinen. Erscheint sie nicht innerhalb einer Minute, prüfen Sie, ob der Code exakt wie kopiert eingefügt wurde (inklusive beider Anführungszeichen) und ob ein von Ihrer Plattform oder einem Plugin (z. B. WP Rocket) verwendeter Seiten-Cache geleert wurde.
