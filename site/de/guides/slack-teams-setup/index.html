Slack- & Teams-Einrichtungsanleitung

Erhalten Sie eine Nachricht, sobald ein Besucher einen Menschen benötigt

WelcoChat benachrichtigt Ihr Team, indem es an eine von Ihnen bereitgestellte Webhook-URL sendet — es gibt keine App zu installieren oder OAuth-Berechtigung zu erteilen. Sie erstellen den Webhook in Slack oder Teams, fügen die URL in den Benachrichtigungsbereich Ihrer WelcoChat-Einrichtungsseite ein, und fertig. Dies funktioniert genauso für die generische Webhook-Option (Zapier, Make oder jedes andere Tool, das eingehende Webhooks empfangen kann).

Slack

  1. Gehen Sie zu api.slack.com/apps und melden Sie sich bei Ihrem Workspace an.
  2. Klicken Sie auf Create New App → From scratch. Geben Sie ihr einen Namen (z. B. "WelcoChat") und wählen Sie Ihren Workspace.
  3. Öffnen Sie in den App-Einstellungen Incoming Webhooks in der linken Seitenleiste.
  4. Schalten Sie Activate Incoming Webhooks ein.
  5. Scrollen Sie nach unten und klicken Sie auf Add New Webhook to Workspace.
  6. Wählen Sie den Kanal, der Übergabebenachrichtigungen erhalten soll, und klicken Sie auf Allow.
  7. Kopieren Sie die angezeigte Webhook-URL (beginnt mit https://hooks.slack.com/services/...).
  8. Gehen Sie in WelcoChat zur Einrichtungsseite Ihres Dienstes → Benachrichtigungen, setzen Sie den Kanal auf Slack und fügen Sie die URL ein.

Microsoft Teams

Microsoft migriert Teams-Kanäle vom alten "Connectors"-System (Office 365 Connector) zu Workflows — verwenden Sie Workflows, wenn diese in Ihrem Tenant verfügbar sind.

  1. Öffnen Sie den Teams-Kanal, der Übergabebenachrichtigungen erhalten soll.
  2. Klicken Sie auf ⋯ (weitere Optionen) neben dem Kanalnamen → Workflows.
  3. Suchen und wählen Sie die Vorlage "Post to a channel when a webhook request is received".
  4. Folgen Sie den Anweisungen, um den Kanal zu bestätigen, und klicken Sie dann auf Create flow (oder Add workflow).
  5. Kopieren Sie die von Teams generierte Webhook-URL.
  6. Gehen Sie in WelcoChat zur Einrichtungsseite Ihres Dienstes → Benachrichtigungen, setzen Sie den Kanal auf Microsoft Teams und fügen Sie die URL ein.

Wenn Ihr Tenant statt Workflows noch den alten "Incoming Webhook"-Connector hat, funktioniert das genauso — fügen Sie dem Kanal den Incoming-Webhook-Connector hinzu, kopieren Sie dessen URL und fügen Sie sie an derselben Stelle ein.

Generischer Webhook (Zapier, Make usw.)

Wählen Sie Webhook als Kanal und fügen Sie die "Catch Hook"-URL Ihres Automatisierungstools ein. WelcoChat sendet eine JSON-Payload mit dem Ereignistyp, einer Nachricht und relevanten IDs (Instanz und Unterhaltung) — bauen Sie Ihre Automatisierung um die Felder herum, die Sie aus dieser Payload benötigen.

Testen

Nachdem Sie einen Kanal und eine Webhook-URL gespeichert haben, verwenden Sie die Schaltfläche Testnachricht senden auf der Einrichtungsseite — sie sendet eine echte Benachrichtigung über denselben Weg, den auch eine Live-Übergabe nutzen würde, sodass Sie bestätigen können, dass sie am richtigen Ort ankommt, bevor Sie sich darauf verlassen.
