So funktioniert WelcoChat

1

Konto erstellen

Registrieren Sie sich und starten Sie Ihre 14-tägige kostenlose Testversion — keine Kreditkarte erforderlich.

2

Inhalte verbinden

WelcoChat crawlt Ihre Website und/oder Sie laden Dokumente und FAQs hoch, um die Wissensdatenbank aufzubauen.

3

Widget anpassen

Name, Avatar, Farben, Begrüßungsnachricht — lassen Sie es wie einen Teil Ihrer Website wirken.

4

Eine Codezeile einbetten

Fügen Sie den Code-Schnipsel in Ihre Website ein. Fertig.

5

Überprüfen und verbessern

Sehen Sie Unterhaltungen und unbeantwortete Fragen in Ihrem Dashboard — die Wissensdatenbank wird im Laufe der Zeit besser.

6

Menschliche Übergabe, immer verfügbar

Der Agent übergibt, wann immer er unsicher ist oder ein Besucher nach einer Person fragt.

Alles, was Sie brauchen, um einen KI-Agenten auf Ihrer Website einzusetzen

Website-Wissensdatenbank

Ihre Website automatisch crawlen, PDFs und Dokumente hochladen, aktuell halten.

Einbettbares Widget

Ein Script-Tag, vollständig anpassbares Erscheinungsbild.

Lead-Erfassung

Strukturierter Name, E-Mail, Firma und Interesse für jede qualifizierte Unterhaltung.

Live-Übergabe an Menschen

Ihr Team wird benachrichtigt und kann live in derselben Unterhaltung über das WelcoChat-Portal antworten — nicht nur eine Benachrichtigung erhalten.

Statistik-Dashboard

Gesprächsvolumen, Übergaberate, erfasste Leads, Zustand der Wissensdatenbank.

Slack-, Teams- & Webhook-Benachrichtigungen

Werden Sie benachrichtigt, sobald ein Besucher einen Menschen benötigt — ein generischer Webhook deckt Zapier, Make oder jedes andere Tool ab.
