Προσθήκη του widget στον ιστότοπό σας

Λειτουργεί με WordPress, Wix, GoDaddy, Squarespace, Shopify και κάθε ιστότοπο που επιτρέπει την εισαγωγή προσαρμοσμένου κώδικα

Το widget του WelcoChat είναι μία μόνο γραμμή κώδικα — μια ετικέτα <script> με το μοναδικό αναγνωριστικό του agent σας. Μόλις ο agent σας είναι ενεργός, αντιγράψτε τον κώδικα από τη σελίδα ρύθμισης της υπηρεσίας σας στο portal και επικολλήστε τον στον ιστότοπό σας ακολουθώντας τις παρακάτω οδηγίες για την πλατφόρμα σας. Το widget θα εμφανίζεται τότε αυτόματα σε κάθε σελίδα — χωρίς σχεδιαστική εργασία και χωρίς εγκατάσταση ανά σελίδα.

WordPress

  1. Από τον πίνακα ελέγχου του WordPress, πηγαίνετε στο Πρόσθετα → Προσθήκη νέου, αναζητήστε το "WPCode" (ή το "Insert Headers and Footers") και εγκαταστήστε και ενεργοποιήστε το.
  2. Ανοίξτε το πρόσθετο — συνήθως στο πλαϊνό μενού, στο Code Snippets → Header & Footer.
  3. Επικολλήστε τον κώδικα WelcoChat στο πεδίο Footer, ώστε να φορτώνεται μετά το περιεχόμενο της σελίδας.
  4. Κάντε κλικ στο Save. Το widget εμφανίζεται πλέον σε κάθε σελίδα του ιστότοπού σας.
  5. Συμβουλή: αν το θέμα σας διαθέτει ήδη ρύθμιση "Custom Code" ή "Header/Footer Scripts" — πολλά θέματα Elementor και Astra την έχουν — μπορείτε να επικολλήσετε τον κώδικα απευθείας εκεί, χωρίς να εγκαταστήσετε πρόσθετο.

Wix

  1. Ανοίξτε τον ιστότοπό σας στον επεξεργαστή του Wix και πηγαίνετε στο Ρυθμίσεις → Προσαρμοσμένος κώδικας (ή αναζητήστε "Custom Code" στην επάνω γραμμή αναζήτησης).
  2. Κάντε κλικ στο + Add Custom Code.
  3. Επικολλήστε τον κώδικα WelcoChat στο πλαίσιο κώδικα.
  4. Στο Add Code to Pages, επιλέξτε All Pages. Στο Place Code in, επιλέξτε Body – end.
  5. Κάντε κλικ στο Apply και δημοσιεύστε τον ιστότοπό σας.

GoDaddy Website Builder

  1. Στον πίνακα ελέγχου του GoDaddy Website Builder (Websites + Marketing), πηγαίνετε στο Settings → Site-wide Code (σε ορισμένα πακέτα βρίσκεται στο Settings → Advanced Tools → Custom Code· διαθέσιμο από το πακέτο Commerce και πάνω).
  2. Επικολλήστε τον κώδικα WelcoChat στο πεδίο Footer ή Body.
  3. Κάντε κλικ στο Save και δημοσιεύστε ξανά τον ιστότοπό σας.
  4. Αν το πακέτο GoDaddy δεν περιλαμβάνει επιλογή εισαγωγής κώδικα, ή ο ιστότοπός σας είναι στην πραγματικότητα WordPress που φιλοξενείται στη GoDaddy, ακολουθήστε αντ' αυτού τα παραπάνω βήματα για WordPress.

Squarespace

  1. Στον πίνακα ελέγχου του Squarespace, πηγαίνετε στο Settings → Advanced → Code Injection (απαιτείται πακέτο Business ή υψηλότερο).
  2. Επικολλήστε τον κώδικα WelcoChat στο πεδίο Footer, ώστε να φορτώνεται σε κάθε σελίδα.
  3. Κάντε κλικ στο Save.

Shopify

  1. Από τη διαχείριση του Shopify, πηγαίνετε στο Online Store → Themes.
  2. Στο τρέχον θέμα σας, κάντε κλικ στο Edit code.
  3. Ανοίξτε το αρχείο theme.liquid μέσα στο φάκελο Layout.
  4. Επικολλήστε τον κώδικα WelcoChat ακριβώς πριν από την ετικέτα κλεισίματος </body>.
  5. Κάντε κλικ στο Save.

Οποιοσδήποτε άλλος κατασκευαστής ιστοσελίδων

Κάθε άλλη πλατφόρμα που έχουμε συναντήσει — Webflow, Weebly, Jimdo, Carrd, Framer, χειροκίνητα κωδικοποιημένος ιστότοπος ή δικό σας CMS — λειτουργεί με τον ίδιο τρόπο: αναζητήστε μια ρύθμιση με όνομα "Custom Code", "Header & Footer Scripts", "Code Injection" ή "Tracking Codes" — συνήθως εκεί προστίθενται και τα εργαλεία live chat και τα scripts ανάλυσης — και επικολλήστε εκεί τον κώδικα ώστε να φορτώνεται σε κάθε σελίδα. Αν ο ιστότοπός σας είναι απλή, χειρόγραφη HTML, επικολλήστε τον κώδικα ακριβώς πριν από την ετικέτα κλεισίματος </body> κάθε προτύπου σελίδας.

Έλεγχος ότι λειτουργεί

Μετά τη δημοσίευση, ανοίξτε τον ενεργό ιστότοπό σας σε νέα καρτέλα του προγράμματος περιήγησης — όχι την προεπισκόπηση του επεξεργαστή — και θα πρέπει να δείτε το συννεφάκι του WelcoChat στην κάτω γωνία. Αν δεν εμφανιστεί μέσα σε ένα λεπτό, ελέγξτε ότι ο κώδικας επικολλήθηκε ακριβώς όπως αντιγράφηκε (μαζί με τα δύο εισαγωγικά), και ότι έχει καθαριστεί τυχόν cache σελίδας που χρησιμοποιεί η πλατφόρμα σας ή κάποιο πρόσθετο (π.χ. WP Rocket).
