Οδηγός ρύθμισης Slack & Teams

Λάβετε ένα μήνυμα τη στιγμή που ένας επισκέπτης χρειάζεται άνθρωπο

Το WelcoChat ειδοποιεί την ομάδα σας δημοσιεύοντας σε μια διεύθυνση URL webhook που παρέχετε — δεν υπάρχει εφαρμογή προς εγκατάσταση ή άδεια OAuth προς παραχώρηση από την πλευρά σας. Δημιουργείτε το webhook στο Slack ή στο Teams, επικολλάτε τη διεύθυνση URL στην ενότητα Ειδοποιήσεις της σελίδας ρύθμισης WelcoChat σας, και έχετε τελειώσει. Αυτό λειτουργεί με τον ίδιο τρόπο για τη γενική επιλογή webhook (Zapier, Make, ή οποιοδήποτε εργαλείο μπορεί να λάβει εισερχόμενο webhook).

Slack

  1. Μεταβείτε στο api.slack.com/apps και συνδεθείτε στον χώρο εργασίας σας.
  2. Κάντε κλικ στο Create New App → From scratch. Δώστε του ένα όνομα (π.χ. "WelcoChat") και επιλέξτε τον χώρο εργασίας σας.
  3. Στις ρυθμίσεις της εφαρμογής, ανοίξτε το Incoming Webhooks στην αριστερή πλευρική μπάρα.
  4. Ενεργοποιήστε το Activate Incoming Webhooks.
  5. Μετακινηθείτε προς τα κάτω και κάντε κλικ στο Add New Webhook to Workspace.
  6. Επιλέξτε το κανάλι που πρέπει να λαμβάνει ειδοποιήσεις παραπομπής, και κάντε κλικ στο Allow.
  7. Αντιγράψτε τη διεύθυνση URL webhook που εμφανίζεται (ξεκινά με https://hooks.slack.com/services/...).
  8. Στο WelcoChat, μεταβείτε στη σελίδα ρύθμισης της υπηρεσίας σας → Ειδοποιήσεις, ορίστε το Κανάλι σε Slack, και επικολλήστε τη διεύθυνση URL.

Microsoft Teams

Η Microsoft μεταβαίνει τα κανάλια Teams από το παλιό σύστημα "Connectors" (Office 365 Connector) στα Workflows — χρησιμοποιήστε τα Workflows εάν είναι διαθέσιμα στον οργανισμό σας.

  1. Ανοίξτε το κανάλι Teams που πρέπει να λαμβάνει ειδοποιήσεις παραπομπής.
  2. Κάντε κλικ στο ⋯ (περισσότερες επιλογές) δίπλα στο όνομα του καναλιού → Workflows.
  3. Αναζητήστε και επιλέξτε το πρότυπο "Post to a channel when a webhook request is received".
  4. Ακολουθήστε τις προτροπές για να επιβεβαιώσετε το κανάλι, στη συνέχεια κάντε κλικ στο Create flow (ή Add workflow).
  5. Αντιγράψτε τη διεύθυνση URL webhook που δημιουργεί το Teams για εσάς.
  6. Στο WelcoChat, μεταβείτε στη σελίδα ρύθμισης της υπηρεσίας σας → Ειδοποιήσεις, ορίστε το Κανάλι σε Microsoft Teams, και επικολλήστε τη διεύθυνση URL.

Εάν ο οργανισμός σας διαθέτει ακόμα μόνο τον παλαιότερο συνδέτη "Incoming Webhook" αντί για Workflows, αυτό λειτουργεί επίσης με τον ίδιο τρόπο — προσθέστε τον συνδέτη Incoming Webhook στο κανάλι, αντιγράψτε τη διεύθυνση URL του, και επικολλήστε την στο ίδιο σημείο.

Γενικό webhook (Zapier, Make κ.λπ.)

Επιλέξτε Webhook ως κανάλι και επικολλήστε τη διεύθυνση URL "catch hook" από το εργαλείο αυτοματισμού σας. Το WelcoChat στέλνει ένα JSON payload με τον τύπο συμβάντος, ένα μήνυμα, και σχετικά αναγνωριστικά (instance και συνομιλία) — δημιουργήστε τον αυτοματισμό σας γύρω από όποια πεδία χρειάζεστε από αυτό το payload.

Δοκιμή

Αφού αποθηκεύσετε ένα κανάλι και μια διεύθυνση URL webhook, χρησιμοποιήστε το κουμπί Αποστολή δοκιμαστικού μηνύματος στη σελίδα ρύθμισης — στέλνει μία πραγματική ειδοποίηση μέσω της ίδιας διαδρομής που θα χρησιμοποιούσε μια ζωντανή παραπομπή, ώστε να μπορείτε να επιβεβαιώσετε ότι φτάνει στο σωστό μέρος πριν βασιστείτε σε αυτό.
