Ajouter le widget à votre site

Compatible avec WordPress, Wix, GoDaddy, Squarespace, Shopify et tout site permettant d'ajouter du code personnalisé

Le widget WelcoChat tient en une seule ligne de code — une balise <script> avec l'identifiant propre à votre agent. Une fois votre agent actif, copiez le code depuis la page de configuration de votre service dans le portail, puis collez-le sur votre site en suivant les instructions ci-dessous pour votre plateforme. Le widget apparaît alors automatiquement sur chaque page — sans travail de design, ni installation page par page.

WordPress

  1. Depuis votre tableau de bord WordPress, allez dans Extensions → Ajouter, recherchez "WPCode" (ou "Insert Headers and Footers"), puis installez et activez l'extension.
  2. Ouvrez l'extension — généralement sous Code Snippets → Header & Footer dans le menu latéral.
  3. Collez votre code WelcoChat dans le champ Footer, afin qu'il se charge après le contenu de la page.
  4. Cliquez sur Enregistrer. Le widget apparaît désormais sur toutes les pages de votre site.
  5. Astuce : si votre thème propose déjà une option "Custom Code" ou "Header/Footer Scripts" — c'est le cas de nombreux thèmes Elementor et Astra — vous pouvez y coller le code directement, sans installer d'extension.

Wix

  1. Ouvrez votre site dans l'éditeur Wix et allez dans Paramètres → Code personnalisé (ou recherchez "Code personnalisé" dans la barre de recherche en haut).
  2. Cliquez sur + Ajouter du code personnalisé.
  3. Collez votre code WelcoChat dans la zone de code.
  4. Sous Ajouter le code aux pages, choisissez Toutes les pages. Sous Placer le code dans, choisissez Body – fin.
  5. Cliquez sur Appliquer, puis publiez votre site.

GoDaddy Website Builder

  1. Dans votre tableau de bord GoDaddy Website Builder (Websites + Marketing), allez dans Paramètres → Code du site (sur certains forfaits, sous Paramètres → Outils avancés → Code personnalisé ; disponible à partir du forfait Commerce).
  2. Collez votre code WelcoChat dans le champ Footer ou Body.
  3. Cliquez sur Enregistrer et republiez votre site.
  4. Si votre forfait GoDaddy n'inclut pas d'option d'insertion de code, ou si votre site est en réalité un WordPress hébergé chez GoDaddy, suivez plutôt les étapes WordPress ci-dessus.

Squarespace

  1. Dans le tableau de bord Squarespace, allez dans Paramètres → Avancé → Injection de code (nécessite un forfait Business ou supérieur).
  2. Collez votre code WelcoChat dans le champ Footer, afin qu'il se charge sur chaque page.
  3. Cliquez sur Enregistrer.

Shopify

  1. Depuis votre administration Shopify, allez dans Boutique en ligne → Thèmes.
  2. Sur votre thème actuel, cliquez sur Modifier le code.
  3. Ouvrez theme.liquid dans le dossier Layout.
  4. Collez votre code WelcoChat juste avant la balise fermante </body>.
  5. Cliquez sur Enregistrer.

Tout autre créateur de site

Toutes les autres plateformes que nous connaissons — Webflow, Weebly, Jimdo, Carrd, Framer, un site codé à la main ou votre propre CMS — fonctionnent de la même façon : cherchez un réglage appelé "Code personnalisé", "Scripts d'en-tête et de pied de page", "Injection de code" ou "Codes de suivi" — c'est généralement là que s'ajoutent aussi les outils de chat en direct et les scripts d'analyse — et collez-y le code pour qu'il se charge sur chaque page. Si votre site est en HTML pur écrit à la main, collez le code juste avant la balise fermante </body> de chaque modèle de page.

Vérifier que ça fonctionne

Après la publication, ouvrez votre site en ligne dans un nouvel onglet — pas l'aperçu de l'éditeur — et la bulle WelcoChat devrait apparaître dans le coin inférieur. Si elle n'apparaît pas en une minute, vérifiez que le code a été collé exactement tel que copié (avec les deux guillemets), et que le cache de page utilisé par votre plateforme ou une extension (ex. WP Rocket) a bien été vidé.
