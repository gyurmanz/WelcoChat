Guide de configuration Slack & Teams

Recevez un message dès qu'un visiteur a besoin d'un humain

WelcoChat notifie votre équipe en publiant sur une URL de webhook que vous fournissez — il n'y a aucune application à installer ni permission OAuth à accorder de votre côté. Vous créez le webhook dans Slack ou Teams, collez l'URL dans la section Notifications de votre page de configuration WelcoChat, et c'est terminé. Cela fonctionne de la même manière pour l'option de webhook générique (Zapier, Make, ou tout outil pouvant recevoir un webhook entrant).

Slack

  1. Allez sur api.slack.com/apps et connectez-vous à votre espace de travail.
  2. Cliquez sur Create New App → From scratch. Donnez-lui un nom (par ex. « WelcoChat ») et choisissez votre espace de travail.
  3. Dans les paramètres de l'application, ouvrez Incoming Webhooks dans la barre latérale gauche.
  4. Activez Activate Incoming Webhooks.
  5. Faites défiler vers le bas et cliquez sur Add New Webhook to Workspace.
  6. Choisissez le canal qui doit recevoir les notifications de transfert, puis cliquez sur Allow.
  7. Copiez l'URL du webhook qui apparaît (commence par https://hooks.slack.com/services/...).
  8. Dans WelcoChat, allez à la page de configuration de votre service → Notifications, définissez le canal sur Slack, et collez l'URL.

Microsoft Teams

Microsoft migre les canaux Teams de l'ancien système « Connecteurs » (Office 365 Connector) vers Workflows — utilisez Workflows si disponible dans votre tenant.

  1. Ouvrez le canal Teams qui doit recevoir les notifications de transfert.
  2. Cliquez sur ⋯ (plus d'options) à côté du nom du canal → Workflows.
  3. Recherchez et sélectionnez le modèle « Post to a channel when a webhook request is received ».
  4. Suivez les invites pour confirmer le canal, puis cliquez sur Create flow (ou Add workflow).
  5. Copiez l'URL du webhook générée par Teams.
  6. Dans WelcoChat, allez à la page de configuration de votre service → Notifications, définissez le canal sur Microsoft Teams, et collez l'URL.

Si votre tenant ne dispose encore que de l'ancien connecteur « Incoming Webhook » au lieu de Workflows, cela fonctionne aussi de la même manière — ajoutez le connecteur Incoming Webhook au canal, copiez son URL, et collez-la au même endroit.

Webhook générique (Zapier, Make, etc.)

Choisissez Webhook comme canal et collez l'URL « catch hook » de votre outil d'automatisation. WelcoChat envoie une charge utile JSON avec le type d'événement, un message et les identifiants pertinents (instance et conversation) — construisez votre automatisation autour des champs dont vous avez besoin dans cette charge utile.

Le tester

Après avoir enregistré un canal et une URL de webhook, utilisez le bouton Envoyer un message test sur la page de configuration — il envoie une véritable notification par le même chemin qu'utiliserait un transfert en direct, afin que vous puissiez confirmer qu'elle arrive au bon endroit avant de vous y fier.
