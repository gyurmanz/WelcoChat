La plupart des visiteurs d'un site web repartent sans jamais poser de question.

Le chat en direct ne fonctionne que si quelqu'un le surveille. Les formulaires de contact sont ignorés. Les pages FAQ sont sautées. Comment fonctionne WelcoChat

1

Créer un compte

Inscrivez-vous et démarrez votre essai gratuit de 14 jours — aucune carte requise.

2

Connecter votre contenu

WelcoChat explore votre site web et/ou vous téléchargez des documents et FAQ pour construire sa base de connaissances.

3

Personnaliser le widget

Nom, avatar, couleurs, message d'accueil — faites-le paraître comme faisant partie de votre site.

4

Intégrer une ligne de code

Collez le code dans votre site. Terminé.

5

Vérifier et améliorer

Consultez les conversations et les questions sans réponse dans votre tableau de bord — la base de connaissances s'améliore avec le temps.

6

Transfert humain, toujours disponible

L'agent transfère chaque fois qu'il n'est pas sûr ou qu'un visiteur demande une personne.
